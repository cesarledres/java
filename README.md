# 📚 Estudos em Java

Este repositório reúne minhas anotações e exercícios práticos em Java, desenvolvidos ao longo da minha jornada de aprendizado em programação. O objetivo é consolidar conhecimentos, praticar lógica de programação e acompanhar minha evolução na linguagem.

---

## 📌 Conteúdos abordados

- Sintaxe básica do Java  
- Variáveis e tipos de dados  
- Estruturas condicionais (`if`, `else`, `switch`)  
- Estruturas de repetição (`for`, `while`)  
- Métodos e funções  
- Lógica de programação

## 💡 Observações
Os exercícios foram desenvolvidos com fins educacionais e podem evoluir conforme o aprofundamento nos estudos. Sinta-se à vontade para explorar os códigos e acompanhar minha evolução!
